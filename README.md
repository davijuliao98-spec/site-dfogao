# 🍲 D'Fogão - Landing Page Responsiva

Site institucional e cardápio online para o restaurante **D'Fogão**. Focado em conversão via WhatsApp e SEO local.

## 🚀 Funcionalidades
- Layout Mobile-First (Totalmente responsivo).
- Botões de chamada para ação (CTA) integrados ao WhatsApp.
- Otimização de SEO para buscas locais.
- Design baseado na psicologia das cores (apetite e tradição).

## 🛠️ Tecnologias
- HTML5
- CSS3 (Flexbox e Grid)
- Google Fonts (Playfair Display & Montserrat)

## 📦 Como usar
1. Clone este repositório.
2. Altere as informações de [Cidade] e [Telefone] no `index.html`.
3. Adicione suas fotos na pasta `/img`.
4. Hospede gratuitamente no **GitHub Pages**.
